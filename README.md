# Broken Wild (prototype v0.1)

A roguelite, open-world RPG prototype where machines and nature share a world with broken physics. Placeholder name, art and numbers.

## Play

Open `index.html` in a desktop browser. Everything is in that one file (HTML, CSS, JavaScript). Progress is saved in the browser's localStorage.

## Controls

- Move: WASD
- Aim and shoot: mouse
- Special: Space or right click
- Interact (repair gates and machines, open the Vault): E
- Recall to the hub: R
- Tech skills, hero stats, journal: 1, 2, 3
- Menu: Esc

## What is in it

- Three classes (Knight, Archer, Wizard) with permanent potion upgrades per class
- A shared Vault at the hub, so gear can pass between classes
- Open world in four rings (Mossy Shallows, Rusted Grove, Gearworks, Corrupted Core), each ring sealed by four rusted gates you can repair in any order
- Zone physics anomalies: curved shots, low friction, pulsing shots
- Wire-matching repair puzzles with a separate Tech skill track
- A three-phase final boss; beating it restores the world and play continues

## Tweaking

Placeholder names and balance values live in the `CONFIG` block at the top of the script in `index.html`.
